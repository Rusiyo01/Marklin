Language cheat sheet
loco train mm2 24           loco alias (mm2 / dcc / mfx + address)
sensor platform 3           sensor alias
power on | off              track power
speed train 400 | 40%       speed 0-1000 or percentage
ramp train 60% 3s           accelerate/brake gradually
dir train fwd | rev | toggle direction (leaves the loco stopped)
func train 0 on | off       functions F0-F31
estop train                 emergency stop of one loco
halt                        stop all locos
switch 5 straight | round   turnout/signal (also dcc:5)
wait 2s | 500ms | 1m        wait
wait random 10s 30s         random wait
wait sensor 3 on [timeout 60s [else label]]
label name / goto name      jumps
if sensor 3 on goto x       conditional jump
if chance 30 goto x         random jump (30 %)
if locked bridge goto x     if another script holds the lock
repeat 5 ... end            loop (repeat without a number = forever)
lock bridge / unlock bridge reserve a section between scripts
log text                    message to the log
exit                        finish
